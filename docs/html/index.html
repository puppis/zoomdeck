Zoomdeck

Zooming presentations written in Markdown and played entirely in the browser.

What Zoomdeck does#

A Zoomdeck presentation is a forest of slides, most often a single tree. Each slide has its own logical canvas and a small animation program; child slides sit inside their parent's canvas as viewports. Presenting means visiting each tree in pre-order: the camera zooms into each child, plays its steps and zooms back out (or cuts, when you prefer), so the audience always sees where a detail belongs; from one root to the next it cuts, as between the pages of a document.

You write slides in a Markdown dialect: prose, LaTeX formulas, images, video, shapes, diagram icons and arrows (crisp or hand-drawn), boxes and blobs around groups of elements, tables, charts, code listings, live web pages, fragments that appear on clicks, and animations such as moves, morphs and effects. When the dialect is not enough, a slide can be a small TypeScript class with the full animation engine at hand. Everything runs live on a WebGL canvas in the browser: a deck loads, records itself once, and then plays forwards and backwards instantly, with an outline, deep links, a pressure-sensitive pen, a highlighter, a whiteboard, a companion tablet, a camera view, a spotlight or laser, links on any element and configurable keys and gestures, and it records a talk (voice, camera and every move on the deck) that plays back on the deck itself or exports as a video, and prints every stage to a PDF. The same deck previews while you edit it and exports to a static folder or to a single HTML file that plays from disk.

See it: the tour deck is itself a Zoomdeck presentation, a tour of every feature with the markup that produces it next to the result. Source: github.com/puppis/zoomdeck.

The tour deck#

The tour is Zoomdeck's own demonstration and the companion of these pages: a presentation in which every chapter shows a feature next to the listing that produces it, organized in the same sections as this documentation. Open the tour: its front page lists the sections and jumps to any of them on a double-click, and each chapter links back to its page here.

The tour is a single self-contained HTML file next to these pages, exported from examples/tour/ when you run npm install (and again by npm run docs); it runs from disk or from any web server, and npm run dev opens the same deck live. Its sources (slides.md, deck.json, code-slides.ts and a few assets) are a good starting point for a deck of your own.

The project#

Zoomdeck lives at github.com/puppis/zoomdeck; this site and the tour are published from it at puppis.github.io/zoomdeck. It needs Node.js 20.19 or newer (or 22.12 or newer) to install and build, and a browser with WebGL 2 to play decks; nothing else, no Python, LaTeX or video tools. Exported decks are plain HTML files.
