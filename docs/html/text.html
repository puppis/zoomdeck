Blocks#

Paragraphs, headings (# to ######), bullet and numbered lists and fenced code blocks are supported. Blank lines separate elements: each paragraph, heading, list item, image, formula and listing is one element with its own attributes. Headings only change the typography; nesting comes from includes.

Lists#

Items start with -, * or +, or with a number and . or ); indenting an item by two or more spaces nests it under the previous one, to any depth. Each item is one element: its marker sits in a column of layout.listIndent (0.6 units, wider when a number needs it), its prose wraps to the rest of the width with a hanging indent, and nested items are shifted by one column per level. Markers are •, – and ◦ by depth; numbered items show their own number with its delimiter, so a list may start at any value. Blank lines between items are allowed, and an indented paragraph after a blank line continues the item without a marker. Attributes in braces work on an item as on any paragraph; an explicit x is the left edge of the list, nested items keep their indentation to its right.

HTML comments are discarded and raw HTML is shown as text. Soft line breaks in the source are joined; an explicit break takes two trailing spaces, a backslash before the newline, or \\.

Inline styling#

Bold, italic, nested emphasis, code spans and inline math ($…$) can be combined freely. A paragraph with inline math stays one element: prose and formulas share one baseline, and the paragraph wraps to its width as a whole.

Colors are written as [text]{color=…} or [text]{style="color:…"} (not both). A color is a palette name (BLUE, RED, TEAL, ORANGE, YELLOW, GRAY, GREEN, PURPLE, with _A to _E variants), a CSS name, a hex value or rgb(…). Nested emphasis and math inherit the span's color. A color-only span stays inline; any other attribute makes the bracketed text a positioned element of its own, which then must be a whole block.

Links#

[label](https://…) renders an underlined label that opens the page in a new tab; mailto: and relative URLs work too. Links are clickable wherever the text is visible on screen, including in parent previews.

Any element can be a link as a whole: href= on a paragraph, heading, image, formula, shape, icon, arrow, brace, box, blob, table, chart or group opens its URL in a new tab when the element is clicked. The element's look does not change, and the link is active wherever the element is on screen and visible.

[[icon: document #paper x=0 y=0 size=1.2 label="the paper" href=https://arxiv.org/abs/1234.56789]]

::: {.group #team x=4 y=0 href=https://example.org/team}
Our team
:::

Typography defaults#

By default prose is set in Latin Modern Roman and code spans in Latin Modern Mono, the OpenType versions of the Computer Modern family LaTeX uses, both bundled with the player; formulas use MathJax's TeX fonts, and a font_size means the same em for all three, so a paragraph with code and formulas inside it looks like one LaTeX paragraph without any tuning. layout.font and layout.codeFont replace the faces ("Georgia", "Fira Code", …) while keeping the size calibration.

Body text uses layout.fontSize (28 by default) and headings layout.headingSize, shrinking slightly per level; code spans use layout.codeFont. Any element can override its size with font_size= and its color with color=, or through a style. A paragraph, heading, arrow label or brace label can also pick its own face with font=: any font the page has, or the bundled handwriting face Zeyada, which pairs with hand-drawn shapes ([A note]{font=Zeyada font_size=36}).
